# Entrega Final - Git y GitHub

## Descripción del proyecto
Proyecto desarrollado como parte de mi formación en la Diplomatura Full Stack. Su objetivo inicial fue practicar los conceptos fundamentales de Git y GitHub mediante la creación de una página web básica con HTML y CSS.

## Tecnologías utilizadas
- HTML5
- Git
- GitHub

## Flujo de trabajo y colaboración

- Se creó la rama `feat-formulario-contacto` para desarrollar la nueva funcionalidad.
- Se registraron los cambios mediante commits con mensajes descriptivos.
- Se publicó la rama en GitHub.
- Se creó un Pull Request hacia la rama `main` para revisar los cambios.
- Finalmente, se integró la funcionalidad mediante un Merge.
