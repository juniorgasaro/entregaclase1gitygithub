# Entrega clase 1 Git y GitHub

## Descripción del proyecto
Proyecto realizado para practicar lo viso en la primera clase de Git y Github.
En este caso creamos un index.html con un Header y un Body simple con los requisitos de la entrega.

## Tecnologías
- HTML
- CSS
- Git
- GitHub

## Cómo empezar

1. Clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `index.html` en el navegador.
